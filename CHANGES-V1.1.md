# NOVA V1.1 — Feedback fixes

## Today
- Compact progress strip; quote removed.
- Timeline uses exact minute positioning rather than grouping an event into its starting hour.
- Dragging into the timeline snaps to 15-minute increments.
- Scheduled tasks are draggable and can be dropped into Unscheduled.
- Scheduled one-off task deletion offers **Move to unscheduled today** or **Delete task**.
- Repeating task deletion offers **Delete this event only**, **Delete this & future**, or **Delete entire series**.
- New tasks default to no duration and no reminder. Status is only shown when editing an existing task.
- Location appears at the right of timeline cards. A **Notes** marker appears when notes are present.
- Repeat options: Daily, Weekdays, Weekends, Weekly/selected days, Monthly, Yearly.
- Habits use one weekday picker and support occurrence/future/series deletion.
- Unscheduled tasks can be reordered by drag on desktop and arrows on mobile.

## Projects
- Added Project Notes for progress updates.
- Added an Archived Projects section and Unarchive action.

## Settings
- Your Day settings are edited as a draft and saved together with one Save button.
- Manual cloud sync now sees the just-saved settings immediately.
- Categories can be moved up/down and deleted.

## Navigation
- Sidebar **+ New task** now opens the Today task composer.
